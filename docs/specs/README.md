## Правила исполнения для ИИ-агентов (Execution Protocol)

1. **Изоляция:** Каждая микроспека выполняется в отдельной свежей сессии (Fresh Context).
2. **TDD:** Сначала запускается проверка — она обязана упасть (`FAILED`). Затем пишется минимальный код для удовлетворения контракта — проверка обязана пройти (`PASSED`).
3. **Атомарный коммит:** После успешной проверки создается коммит вида `feat(spec): close <SPEC-ID> - <краткое описание>`.
4. **Откат при сбое:** При любой неразрешимой ошибке или таймауте ветка откатывается к последнему валидному коммиту (`git reset --hard HEAD`), а задача перезапускается или передается на анализ.
