# Инструкции для AI-агентов репозитория

## Карта проекта и документация

В начале работы с кодом выполните `tree docs`. Если команды нет, выполните `find docs -maxdepth 2 -type f | sort`. Дерево — только навигация, откройте нужные документы явно. Перед правкой документации прочитайте `docs/document_writing_RU.md`.

Ключевые документы: `docs/architecture_RU.md` (компоненты и потоки данных), `docs/setup_RU.md` (конфигурация), `docs/security_RU.md` (границы безопасности), `docs/api_RU.md` (wire-контракты), `docs/features_RU.md` (поведение), `docs/troubleshooting_RU.md` (диагностика) и `docs/external-claims_RU.md` (датированные внешние сведения).

## Языковая политика

`README.md` и документы `name.md` — основные английские версии. Русские переводы — `README_RU.md` и `name_RU.md`. Синхронизируйте факты, идентификаторы и процедуры; правила — в `docs/document_writing_RU.md`.

Это платформенный плагин Hermes Agent для MAX. Голос транскрибирует Hermes Core, а не плагин.

## Настройка и эксплуатация

Используйте актуальные инструкции и официальную документацию MAX; не угадывайте требования API. Зависимости устанавливайте в Python Hermes. `MAX_BOT_TOKEN` и `MAX_WEBHOOK_SECRET` — секреты. `MAX_WEBHOOK_URL` включает webhook; иначе стартует polling и может удалять найденные старые subscriptions. Webhook без секрета должен закрываться fail-closed. Перед сменой режима проверьте subscriptions. STT настраивается в Hermes Core.

Не запускайте `scripts/diagnose.sh --send` без явного согласования адресата. Не перезапускайте production, не публикуйте, не push/merge без разрешения пользователя.

## Инварианты разработки

- Сохраняйте относительные package-imports и проверяйте импорт через plugin loader, не только из CWD репозитория.
- Считайте callback payloads и media URL недоверенными. Сохраняйте авторизацию владельца, SSRF/DNS-защиту, лимиты загрузки и запрет утечки Authorization на сторонние origin.
- Версии, конфигурацию и число тестов подтверждайте исходниками и проверками, не памятью.
- Запускайте проверки документации и релевантные тесты; пропуск проверки не означает успех.
