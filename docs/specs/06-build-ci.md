# Micro-Specs: Группа BUILD & CI (Сборка, изоляция тестов и Quality Gates)

Стандарт: Micro-Spec («OpenSpec без OpenSpec»). Источник: задачи `BUILD-01..03` из `BACKLOG.md`.

---

### ID: BUILD-INSTALL-01
* **Требование:** Репозиторий плагина собирается в режиме editable install (`pip install -e '.[dev]'`) без ошибки множественных top-level пакетов.
* **Условие:** Установка выполняется в чистый виртуальный venv на Python 3.11+.
* **Ожидаемый результат:** `pyproject.toml` содержит явную конфигурацию `find = {where = ["."], include = ["max*", "mixins*"]}` или переносит вспомогательные модули внутрь пакета; команда завершается с кодом 0.
* **Проверка:** `pip install --dry-run -e .` (или реальная сборка в venv) завершается с кодом 0.
* **Не входит:** Публикация пакета в PyPI.

---

### ID: BUILD-ENV-01
* **Требование:** Сборка тестового набора pytest выполняется в произвольном каталоге без зависимости от имени checkout или запущенного gateway.
* **Условие:** Тесты запускаются из временной директории с кастомным путем.
* **Ожидаемый результат:** `tests/conftest.py` корректно разрешает импорты без `ImportError: No module named 'max.adapter'`; тесты собираются (collection pass).
* **Проверка:** `pytest --collect-only -q` возвращает список тестов с кодом 0.
* **Не входит:** Запуск тестов с реальным обращением к live-серверам MAX Bot API.

---

### ID: BUILD-GATE-01
* **Требование:** Статические анализаторы (Ruff, Bandit) охватывают все production-файлы плагина, включая каталог `mixins/`.
* **Условие:** Запуск линтеров в рамках CI pipeline.
* **Ожидаемый результат:** Команды `ruff check .` и `bandit -r . -x ./tests` проверяют корневые модули и `mixins/` без ошибок и исключений.
* **Проверка:** `ruff check . && bandit -r . -x ./tests` завершается с кодом 0.
* **Не входит:** Проверка стилей фронтенда Desktop (JS/CSS).
