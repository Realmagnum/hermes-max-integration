# Интерактивный выбор сессий с кнопками — Micro-Spec

[English version](20261016-interactive-sessions.md)

Поправка 2026-10-21: режим списка и количество заменены контрактами [SLP-001–006](20261021-session-list-policy_RU.md). Остальные контракты интерактивного выбора сохраняются.
Дата: 2026-10-16. Статус: специфицировано, реализация в процессе. Источник: запрос пользователя на интерактивный вывод списка кросс-платформенных сессий и выбор через inline-кнопки MAX, автоудаление сообщения со списком при отмене/выборе и карточку восстановления контекста. Базовый коммит: `877df52`; целевое развёртывание: тестовая установка на сервере SRV-TEST.

## Цели и границы

Замена текстового вывода команды `/sessions` на интерактивный интерфейс с inline-клавиатурой. Список отображает недавние сессии со всех платформ (CLI, Telegram, MAX, Desktop, WebUI), оформленный визуальными отступами, жирной нумерацией, эмодзи платформы-источника, цитатами исходного запроса пользователя, моноширинным временем `YYYY/MM/DD HH:MM` и счётчиком сообщений. Кнопки выбора сгруппированы по 5 штук в ряду, плюс нижний ряд действий «Обновить» и «Отмена».

При выборе сессии или отмене сообщение со списком удаляется через `delete_message` для предотвращения захламления чата. При выборе сессии адаптер переключает активную сессию чата и отправляет компактную карточку напоминания контекста с исходной задачей и последним сообщением.

Не входит в скоуп:
- Изменение логики переключения сессий в ядре Hermes Core или схемы БД.
- Предоставление выбора сессий посторонним пользователям без прав владельца (строгое соблюдение SEC-01 и SEC-05).

## Контракты

| ID | Триггер / контекст | Требуемый результат | Приёмочные свидетельства | Статус |
|---|---|---|---|---|
| SESS-001 | Авторизованный владелец отправляет `/sessions` или `/resume` (без аргументов) | Запрос в `SessionDB` (до 20, по умолчанию 15); форматирование с жирными номерами, эмодзи источников, цитатами исходного запроса, моноширинным временем `YYYY/MM/DD HH:MM`, числом сообщений и пустыми строками-разделителями | Модульный тест структуры сообщения, форматирования даты и отступов | Implemented |
| SESS-002 | Отправка сообщения выбора сессий | Сообщение содержит вложение `inline_keyboard` с 5 кнопками в ряду (`{emoji} {i}`) и нижний ряд (`🔄 Обновить`, `❌ Отмена`); callback payload с префиксом `session:` (`session:pick:<id>`, `session:cancel`, `session:refresh`) | Модульный тест рядов клавиатуры, числа кнопок, подписей и payload | Implemented |
| SESS-003 | Поступление callback `session:*` | Проверка, что отправитель — авторизованный владелец, и callback соответствует зарегистрированному ID сообщения (SEC-01). Отклонение чужих пользователей, просроченных состояний и незарегистрированных сообщений (fail-closed) | Модульные тесты отклонения неавторизованных пользователей, истечения TTL и несовпадения ID сообщения | Implemented |
| SESS-004 | Нажатие кнопки «❌ Отмена» владельцем | Удаление сообщения со списком через `delete_message(chat_id, message_id)`; очистка состояния выбора сессий; отсутствие переключения сессии | Модульный тест вызова `delete_message` с нужным `message_id` и отсутствия события возобновления | Implemented |
| SESS-005 | Нажатие кнопки «🔄 Обновить» владельцем | Повторный запрос в `SessionDB` и обновление сообщения актуальным списком сессий и кнопками | Модульный тест повторного запроса к БД и обновления/переотправки сообщения | Implemented |
| SESS-006 | Нажатие кнопки сессии владельцем (`session:pick:<id>`) | Удаление сообщения со списком; отправка компактной карточки подтверждения контекста (данные сессии, цитата исходной задачи, цитата последнего сообщения); возврат `MessageEvent` с `/resume --all <session_id>` для переключения в ядре | Модульный тест удаления списка, отправки контекстной карточки и возврата события `/resume --all <id>` | Implemented |

## Опорные точки реализации

- `mixins/sessions.py`: `_handle_cross_sessions`, форматирование сессий, извлечение цитат, построение интерактивной клавиатуры.
- `adapter.py`: диспетчеризация в `_on_callback` для `prefix == "session"`, обработчики `_handle_session_callback`, `_handle_session_pick`, `_handle_session_cancel`, `_handle_session_refresh`.
- `tests/test_interactive_sessions.py`: полный набор модульных тестов для SESS-001 — SESS-006.
