## Security

- [ ] **SEC-01 · P1 · S/R — Approval callback authorization.** `adapter.py:1538–1640`, `mixins/buttons.py:225–227`: a nonempty user_id suffices; approval stores only session_key. A group participant can approve another user's dangerous command, including always; slash-confirm has an analogous path. A mocked resolver received owner-session from a disallowed user. **Acceptance:** common authorization before dispatch/pop; state bound to owner_user_id/chat_id/message_id with TTL; wrong user/chat/stale button neither invokes resolver nor deletes state. Also inspect clarify and model picker.
- [ ] **SEC-02 · P1 · S/R — Do not forward the bot token to arbitrary attachment URLs.** `adapter.py:343–346, 975–1087`: audio/image/document GET includes Authorization on the original URL. A mock confirmed a fake token sent to an unrelated HTTPS origin. Requires control over a URL in an accepted event; ordinary MAX client feasibility is unconfirmed, an unprotected webhook provides a path. **Acceptance:** separate token-free download client; only explicitly trusted HTTPS origins receive authorization if necessary; original URL and redirect tests, no token in errors/logs.
- [ ] **SEC-03 · P1 · S/R — Download SSRF.** `adapter.py:930–947, 982–1069`: hostnames not understood by ipaddress are accepted; DNS private/loopback resolution is unchecked. The validator accepted alternative loopback representations. **Acceptance:** restrict schemes/origins; when DNS is supported, validate all A/AAAA and prevent connection-time rebinding; private/link-local/loopback/IPv6/nonstandard IP and redirects tested without contacting real internal networks.
- [ ] **SEC-04 · P1 · S — Secretless webhook.** `adapter.py:221–230`, `mixins/webhook.py:63–116`: warning instead of failure; sender comes from JSON. A public endpoint permits forging an allowed user_id. **Acceptance:** fail closed without a valid secret; verify header before body processing; separate explicit loopback-only development opt-in if needed; safe examples and missing/invalid secret tests.
- [ ] **SEC-05 · P1 · S/R — Global session access.** `adapter.py:201–205, 639–643, 712–732`, `mixins/sessions.py:42–106`: empty allowlist with allow_all_users=False permits direct /sessions before core; titles/previews/IDs across platforms are exposed. **Acceptance:** deny by default before side effects; cross-session disabled by default or owner-only with explicit opt-in; /sessions, search, /resume with/without arguments tested. Verify core resume contract separately; bypass of all ordinary messages is not established.
- [ ] **SEC-06 · P1 · S/R — Group allowlist semantics.** `adapter.py:645–654`: an empty list yields True; OR neutralizes the other configured list. **Acceptance:** define OR/AND policy, empty lists do not open access; empty/set × user/chat × open/closed/allowlist matrix including direct commands.
- [ ] **SEC-07 · P2 · S — Incoming media limits.** `adapter.py:991–1087`: GET buffers the entire body; 50 MB applies only to upload. **Acceptance:** streaming cap on actual bytes, total deadline, attachment count/aggregate size, concurrency and partial-file cleanup; missing/false Content-Length, slow/infinite response and disk exhaustion tests.

## Implementation quality

- [ ] **CODE-01 · P1 · S/R — Polling HTTP backoff.** `adapter.py:480–499`: HTTP 429/401/5xx bypass exception backoff; four mocked 429 responses produced four requests without delays. **Acceptance:** Retry-After, bounded exponential backoff/jitter, correct fatal authentication state; virtual-clock status and network-error tests.
- [ ] **CODE-02 · P2 · S/R — Chunking loses text.** `adapter.py:1114–1116, 1233–1236`: numbering causes another truncation without carrying the tail; 7800 input characters → 7788 useful output characters. **Acceptance:** account for prefixes before splitting; concatenated transmitted payload preserves source content; boundaries, Unicode, paragraphs and code tested.
- [ ] **CODE-03 · P2 · S/R — Streaming isolation and flush.** `adapter.py:1298–1314`: throttle/pending are adapter-wide; two chats produced one PUT, pending has no independent delivery. **Acceptance:** per-message/chat state, guaranteed flush/finalize, correct timer cancellation; concurrent-chat and last-throttled-edit tests.
- [ ] **CODE-04 · P2 · S/R — Model IDs containing colons.** `adapter.py:1728–1758, 1881–1885`: llama3:8b is parsed as model llama3 and provider 8b:ollama. **Acceptance:** opaque ID or unambiguous encoding; round-trip Ollama tags and OpenRouter :free, malformed/expired payload.
- [ ] **CODE-05 · P2 · S — False webhook connected state.** `mixins/webhook.py:138–152`, `adapter.py:350–375`: registration failure does not block connected; /me permits statuses other than 401. **Acceptance:** validate transport/HTTP/body success, clean up client/runner on failure; distinguish health from readiness; MockTransport 403/429/500/timeout/success=false scenarios.
- [ ] **CODE-06 · P2 · S — Model picker isolation.** `adapter.py:1733–1736, 1824–1833, 1960–1978`: state keyed only by chat; an old message may invoke a new callback. **Acceptance:** owner/session/message binding, TTL, stale-button tests, two users/sessions in one chat.
- [ ] **CODE-07 · P2 · S/V — Lifecycle and core contract.** `adapter.py:267, 343–347, 390–405, 465–467, 505–519`: inspect repeated/concurrent connect, awaiting cancelled tasks before client close, inherited _mark_connected/_running. The latter is an unverified contract, not a proven failure. **Acceptance:** pinned compatible core, connect→disconnect→connect and cancellation/finally tests; no client/task leaks.
- [ ] **CODE-08 · P2 · S — Backpressure and dedup.** `adapter.py:263, 483–489, 517–519, 634–637`: queue/handler count unbounded; dedup pruning removes old records but does not guarantee the advertised hard cap on fresh entries. **Acceptance:** bounded queue/concurrency/dedup, explicit overload policy, burst/load tests and metrics.
