# Micro-Specs: Группа LOCALES & DESKTOP (Локализация и интеграция с Desktop UI)

Стандарт: Micro-Spec («OpenSpec без OpenSpec»). Источник: планы `2026-09-30_130500-max-plugin-locales-pack.md` и `2026-09-29_234621-max-sessions-desktop-plugin.md`.

---

### ID: LOCALE-PACK-01
* **Требование:** Плагин MAX объявляет поддержку языковых пакетов через манифест `provides_locales` (`ru-RU`, `en-US`).
* **Условие:** Система загрузки плагинов опрашивает плагин на наличие ресурсов локализации.
* **Ожидаемый результат:** Каталоги `locales/ru-RU.json` и `locales/en-US.json` содержат валидные JSON-структуры с переводами системных кнопок и сообщений плагина.
* **Проверка:** `pytest -q tests/test_ru_en_parity.py -k "test_locales_json_valid_and_present"` завершается с кодом 0.
* **Не входит:** Модификация системных строк ядра Hermes Desktop.

---

### ID: LOCALE-FALLBACK-01
* **Требование:** При отсутствии ключа перевода в целевом языке система возвращает английский перевод по умолчанию без вызова исключения `KeyError`.
* **Условие:** Код запрашивает ключ `t("buttons.missing_key")`, отсутствующий в `ru-RU.json`, но присутствующий в `en-US.json`.
* **Ожидаемый результат:** Возвращается строка из `en-US.json` (или сам ключ при полном отсутствии); приложение продолжает работу без сбоя.
* **Проверка:** `pytest -q tests/test_ru_en_parity.py -k "test_translation_fallback_to_english"` завершается с кодом 0.
* **Не входит:** Автоматический перевод через онлайн-API.

---

### ID: DESKTOP-SESSION-01
* **Требование:** Модуль отображения сессий MAX в Desktop UI фильтрует список строго по платформе `max` и поддерживает постраничную навигацию.
* **Условие:** Desktop UI запрашивает сессии для отображения в боковой панели интеграции MAX.
* **Ожидаемый результат:** Возвращаются только сессии с платформой `max`; сессии Telegram/Discord не подмешиваются; размер ответа ограничен параметром `limit`.
* **Проверка:** `pytest -q tests/test_cross_session.py -k "test_desktop_session_listing_scoped_to_platform"` завершается с кодом 0.
* **Не входит:** Полнотекстовый поиск по содержимому всех исторических сессий (FTS).
