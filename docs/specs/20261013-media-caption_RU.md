# Подпись вложения — Micro-Spec

[Английская версия](20261013-media-caption.md)

Источник: поручение пользователя, 2026-10-13: файл без текста подписывать именем файла, иначе `File`. Исходная версия плагина: `3df6518`; проверенные Core: `7157422022ff06f3e632d1dd394ee1253b17ad37` и upstream `4957bbd0a0f6a1c3fe8217dc4a66d072971f5b63`.

## Область и контракты

Использовать публичный hook `transform_llm_output` для ответов агента MAX до извлечения вложений Core. Добавлять подписи при прямой отправке адаптером и standalone sender. Сохранить авторский текст, другие платформы, ошибки доставки, credentials и проверку файлов. Core не изменять. Прямой `hermes send` и маршруты cron, не вызывающие этот hook, по-прежнему требуют текста от вызывающего кода: плагин не перехватывает их ранний отказ Core. Для hook нужен `platform=max` от Core; неизвестная платформа остаётся без изменений.

| ID | Условие | Наблюдаемый результат / приёмка | Статус |
|---|---|---|---|
| CAP-001 | Подпись отсутствует или содержит только пробелы | Использовать basename, включая Windows paths, либо явное имя файла; не раскрывать каталог; без имени использовать `File` | Реализовано; изолированная приёмка пройдена |
| CAP-002 | Есть авторский текст | Сохранить его точно; отправку только текста не менять | Реализовано; изолированная приёмка пройдена |
| CAP-003 | Ответ агента MAX содержит только MEDIA markers | Публичный hook добавляет первое имя файла до извлечения медиа Core; реальный public router принимает текст с файлом; другие платформы и ответы с подписью не меняются | Реализовано; изолированная приёмка пройдена |
| CAP-004 | Адаптер/standalone отправляет вложение без подписи | Payload вложения содержит резервную подпись; смысл ошибок и частичной доставки сохраняется | Реализовано; изолированная приёмка пройдена |
| CAP-005 | Модель просят отправить локальный файл в MAX | Зарегистрированный platform hint объясняет создание/доступ к существующему файлу и финальную строку MEDIA без отдельного API tool; нельзя выдумывать несуществующие файлы | Реализовано; регистрация проверена; живая доставка подтверждена пользователем 2026-10-14 |

## Доказательства

CAP-001–004 реализованы в `media_caption.py`, `adapter.py`, `mixins/media_upload.py` и `mixins/standalone.py`; проверены через `tests/test_media_caption.py` и `tests/test_core_send_router.py` на Core `ca13a7828acd2ba8c75e1c1d1694cbc1aee7df3f`. Проверки доставки: 52 passed; полный итоговый набор: 796 passed; проверки подписей с реальной регистрацией публичного hook: 15 passed. В исходниках minimum Core 0.21.4 есть тот же публичный hook и platform context; runtime не проверен, поскольку в локальном окружении Python 3.12 отсутствует Core. Изолированная сборка wheel прошла, helper включён в пакет. Пользователь подтвердил живую доставку файла в MAX 2026-10-14; это подтверждение не распространяется на прямой CLI media-only. Ограничение прямого CLI media-only остаётся открытым в catalog MS-011.
